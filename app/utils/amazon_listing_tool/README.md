用户只上传一张商品原图
例如：扳手、钳子、电钻、五金件、机械零件

系统自动生成多张不同使用场景图
例如：工作台维修、水管维修、汽车维修、自行车维修、家装安装

商品可以根据不同场景自动：
- 变大
- 变小
- 改变位置
- 轻微旋转
- 进入不同使用环境

但用户不手动指定：
- scale
- x / y
- rotation

这些由大模型根据场景自动规划。

同时，工具类 / 五金类商品需要尽量避免：
- 工具结构变形
- 扳手钳口变化
- 调节蜗轮消失
- 手柄孔变化
- 商品变成另一个相似工具
